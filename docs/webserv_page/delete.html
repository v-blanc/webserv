DELETE — Démo

Simuler une requête DELETE

Cliquer sur le bouton enverra une requête HTTP DELETE vers /resource-to-delete (via fetch).

Tester depuis la ligne de commande :

curl -v -X DELETE http://localhost:8080/resource-to-delete
Ton serveur peut répondre 200/204/404 selon la ressource et ta logique.

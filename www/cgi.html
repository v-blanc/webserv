How CGI Works
# Server receives request: GET /cgi-bin/hello.py?name=42 HTTP/1.1 # Server forks a child process: fork() → execve("/cgi-bin/hello.py", ...) # Server sets environment variables: REQUEST_METHOD=GET QUERY_STRING=name=42 SERVER_NAME=localhost SERVER_PORT=8080 # For POST: server pipes body → stdin # CGI writes response → stdout # Server forwards stdout → client

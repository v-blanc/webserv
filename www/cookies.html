Set Cookie — Client Side (document.cookie)

Manually set a cookie

Creates a cookie directly in the browser. Useful to pre-populate cookies before a request so you can test that your server reads the Cookie: header correctly.

Set-Cookie: session_id=abc123xyz; Max-Age=3600; Path=/
Set Cookie — Via CGI (Set-Cookie header)

Ask server to set a cookie

Sends a GET to your CGI cookie script. The CGI outputs a Set-Cookie: header and the browser stores it. Tests that your server forwards CGI headers to the client.

GET /cgi-bin/cookie.py?action=set&name=webserv_session&value=user42 HTTP/1.1

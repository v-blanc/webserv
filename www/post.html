POST Requests

Test form submissions, JSON payloads, file uploads, and body size handling on your WebServ implementation.

application/x-www-form-urlencoded

Form POST

Sends data encoded as key=value&key2=value2 — the default HTML form encoding.

POST /cgi-bin/form.py HTTP/1.1 Content-Type: application/x-www-form-urlencoded Content-Length: 54 name=John+Doe&email=john%4042.fr&school=42+Paris&message=Hello+WebServ%21
RESPONSE—
application/json

JSON POST

Sends a JSON body. Your server should read Content-Type: application/json and pass the body to CGI via stdin.

RESPONSE—
multipart/form-data — File Upload

File Upload

Tests multipart body parsing. WebServ must correctly handle Content-Type: multipart/form-data; boundary=… and extract file data.

POST /cgi-bin/form.py HTTP/1.1 Content-Type: multipart/form-data; boundary=----WebKitFormBoundary Content-Length: <calculated> ------WebKitFormBoundary Content-Disposition: form-data; name="description" ... ------WebKitFormBoundary Content-Disposition: form-data; name="file"; filename="..." Content-Type: <mime-type>
